# Review Artifacts

本目录用于保存项目中的 review、方案评审、架构评审和 review 后最终方案。

## 规则

- 重要 review 必须落盘到本目录。
- 文件名使用 `YYYY-MM-DD-<topic>-review.md` 或 `YYYY-MM-DD-<topic>-final-plan.md`。
- Review 文档必须保留结论、范围、主要发现、最终建议和后续门禁。
- 未经 OpenSpec 批准的方案不得放入 `docs/superpowers/plans/` 作为可执行计划。
