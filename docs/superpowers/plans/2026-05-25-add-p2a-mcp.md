## Steps

### Step 1: Add MCP SDK dependency

File: `agent-runtime/package.json`

- 添加 `@modelcontextprotocol/sdk` 到 dependencies
- pnpm install

验证: `pnpm install && pnpm typecheck`

### Step 2: McpRegistry implementation

File: `agent-runtime/src/mcpRegistry.ts`

- `McpServerConfig` type
- `McpToolEntry` type with serverName + tool definition
- `loadMcpConfig()`: project root 优先
- `class McpRegistry`:
  - `init()`: spawn + initialize + tools/list per server
  - `listTools()`: return all tools with `_source` tag
  - `execute(serverName, toolName, args, timeoutMs?)`: tools/call → ToolCallResponse-shape
  - `shutdown()`: cleanup all clients
- 错误处理：start失败 / timeout / unavailable

验证: `pnpm typecheck`

### Step 3: ToolRegistry merge

File: `agent-runtime/src/toolRegistry.ts`

- 引入 McpRegistry 作为可选依赖
- `getFrozenCatalog`: 合并 catalog + MCP tools；冲突 catalog 优先
- 新增 `resolveSource(toolName)`: "catalog" | "mcp:{server}"
- 给模型的 tools 列表剥离 `_source`

验证: `pnpm typecheck`

### Step 4: agentLoop 路由

Files: `agentLoop.ts`, `agentStreamLoop.ts`

- 工具执行处加 source 判断
- catalog → 现有 javaClient.executeTool
- mcp → mcpRegistry.execute

验证: `pnpm typecheck`

### Step 5: Server 集成

File: `agent-runtime/src/server.ts`

- createServer 时 init McpRegistry（可注入用于测试）
- 注入到 ToolRegistry / AgentLoop / AgentStreamLoop
- Fastify onClose hook → mcpRegistry.shutdown()

验证: `pnpm typecheck`

### Step 6: MCP_REQUIRE_APPROVAL opt-in

File: `agent-runtime/src/beforeToolUse.ts`

- 在 decisions 返回前检查 env，对 MCP source 的 tool 强制 REQUIRE_APPROVAL
- 需要把 source 信息传到 beforeToolUse

验证: `pnpm typecheck`
